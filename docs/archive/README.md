# Archivo documental histórico de Dentaris

Los documentos de esta carpeta se conservan exclusivamente por trazabilidad histórica. No son fuente de verdad ni evidencia vigente de funcionalidades, cobertura, seguridad, despliegues o aptitud para producción.

Para conocer la clasificación y el motivo de archivo, consultar [`../DOCUMENTATION-AUDIT-DENTARIS.md`](../DOCUMENTATION-AUDIT-DENTARIS.md).

La documentación vigente debe contrastarse siempre con el código, las pruebas y la configuración actuales de Dentaris.
